# I2C BSP

`IIC_Register()` 创建一个设备实例。配置中传入已由 CubeMX 初始化的硬件句柄、
7 位地址和有限超时。最多 4 个实例；同一句柄、同一地址不能重复注册。

`IIC_Is_Ready/Transmit/Receive` 返回 HAL 状态并记录到实例的 `last_status`。
所有传输均为同步阻塞，不需要配置接收回调；发送缓冲区在返回后可以复用。

BSP 只负责外设访问，不包含 OLED 命令，也不引用 APP 或 OLED 的头文件。
OLED 等模块可以通过不同实例共享一条 I2C 总线。
当前只支持主循环单调用者；未来在 RTOS 下共享总线时，锁应按硬件总线管理。
